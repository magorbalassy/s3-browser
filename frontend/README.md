# S3 Browser – frontend

Angular 22 (standalone, zoneless, signals, signal forms) with Angular Material 3.

## Development

Run the backend on port 8000 (see the root README), then:

```bash
npm install
npm start          # http://localhost:4200, /api is proxied to http://localhost:8000
```

## Scripts

| Command                | What it does                                                      |
| ---------------------- | ----------------------------------------------------------------- |
| `npm start`            | Dev server with the API proxy (`proxy.conf.json`)                 |
| `npm run build`        | Production build into `dist/s3-browser/browser`                   |
| `npm run test:ci`      | Unit tests (Vitest), single run                                   |
| `npm test`             | Unit tests in watch mode                                          |
| `npm run format:check` | Prettier check (`npm run format` to fix)                          |
| `npm run gen:api`      | Regenerate the typed API client in `src/app/api` from the backend |

## API client

`src/app/api` is generated by [ng-openapi-gen](https://github.com/cyclosproject/ng-openapi-gen)
from the backend's OpenAPI schema (`backend/openapi.json`, written by `s3-browser openapi`).
Do not edit it by hand: change the backend's Pydantic models, then run `npm run gen:api`.
CI fails if the committed client is out of date.

## Layout

```
src/app/
  api/                 generated API client (models + typed functions)
  core/                session store, folder-size streams, theme, notifier, guard, interceptor
  layout/top-bar/      toolbar: endpoint, bucket picker, theme toggle, disconnect
  pages/connect/       connection form
  pages/buckets/       bucket list
  pages/browser/       folder view: /b/<bucket>/<folder path>
  shared/              breadcrumbs, folder size cell, bytes pipe, API error helper
```
